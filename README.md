# Telegram 频道/群聊 视频图片下载工具

把指定 Telegram 频道/群聊里的 **视频和图片** 批量下载到本地硬盘。
自动按 `频道名/消息ID_文件名` 整理保存，支持断点续传、暂停继续、大文件并行加速下载。

## ✨ 功能

### 核心能力
- 🎬 视频 + 图片(含 GIF) 全部下载，自动识别消息类型(音频/贴纸/文档自动排除)
- ⏸ **暂停 / 继续 / 结束**：下载中按 `P` 暂停、`R` 继续、`Q` 结束(已下载的保留)
- 🔁 **断点续传**：已下载文件自动跳过；大文件分片级续传，中断后重跑接续，绝不重复下载
- ⚡ **并行加速**：>4MB 文件自动 8MB 分片 × 4 连接并行下载(约 3~4 倍提速)
- 🛡 下载停滞 90 秒自动掐断重试(代理断流自愈)，单条最多重试 4 次；失败记录到 `失败清单.txt`
- 🌐 自动跟随系统代理(v2rayN 等)；也可在 config.json 指定

### 四种下载模式

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| **1 - 日期范围** | 按起止日期扫描下载 | 知道时间范围，下载某段时间的内容 |
| **2 - 链接→最新** | 从指定消息链接开始，下载到频道最新 | 补下载某条消息之后的所有内容 |
| **3 - 链接→链接** | 下载两条消息链接之间的所有媒体 | 精确控制下载区间 |
| **4 - 单条链接** | 只下载指定的一条消息 | 单条大文件或特定消息 |

## 🚀 快速开始

### 第一步：申请 API 凭证(仅独立使用需要)

1. 打开 https://my.telegram.org 并登录
2. 进入 **API development tools**
3. 新建一个 app，复制 `api_id` 和 `api_hash`
4. 编辑 `config.json`，填入：

```json
{
  "api_id": "你的数字ID",
  "api_hash": "你的hash",
  "proxy": "system"
}
```

> 💡 如果本机已装有同作者的《TG 频道搬运机器人》(同目录上一级)，本工具会自动复用它的凭证和登录状态，这步可跳过。

### 第二步：登录(仅首次)

双击 `下载工具.bat`，按提示输入手机号 + 验证码登录。
(若复用搬运机器人的登录则自动跳过)

### 第三步：选择下载模式

程序启动后会显示当前配置和模式，按提示选择：

```
[下载模式]
  1 - 按日期范围 (原有模式)
  2 - 从链接到最新  (单条消息链接 → 频道最新)
  3 - 从链接到链接  (两条消息链接区间)
  4 - 单条链接      (只下指定消息)
```

### 模式 1: 日期范围

```
请输入频道/群聊链接或ID (t.me/xxx 或 -100xxxx 或 @用户名): LouChu6
开始日期(含, 示例 2026-01-01) [2026-08-01]: 
结束日期(含) [2026-08-28]: 
保存目录 [downloads]: 
```

### 模式 2: 链接→最新

从指定消息开始下载，直到频道最新：

```
起始消息链接 (t.me/.../编号): https://t.me/LouChu6/123
```

### 模式 3: 链接→链接

下载两条消息之间的所有媒体：

```
起始消息链接 (t.me/.../编号): https://t.me/LouChu6/100
结束消息链接 (t.me/.../编号): https://t.me/LouChu6/200
```

> 💡 如果填反了起止链接，程序会自动交换。

### 模式 4: 单条链接

只下载指定的一条消息：

```
消息链接 (t.me/.../编号): https://t.me/LouChu6/123
```

**链接格式支持**：
- `https://t.me/channel/123`
- `https://t.me/channel/post/123`
- `https://t.me/username/456`
- `t.me/channel/789`
- `https://t.me/c/123456/789` (私聊频道)

## ❓ 常见问题

**Q: 提示「未找到 API 凭证」?**
按上面第一步申请并填入 config.json。

**Q: 提示「解析频道失败」?**
确认链接正确、账号已加入该频道/群聊。可在工具里输入 `@用户名` 或使用数字 ID。

**Q: 下载很慢?**
单文件已用分片并行加速。可换更快的代理节点，或凌晨网络空闲时段下载。

**Q: 暂停后重跑会重新下载吗?**
不会。已下载的文件和分片自动跳过/接续，只补缺失部分。

**Q: 中文乱码?**
bat 已自动设置 utf-8 编码，一般不会出现。
